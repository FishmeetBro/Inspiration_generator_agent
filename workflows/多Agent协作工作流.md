# 多 Agent 协作工作流

## 总体原则

统一流转顺序：

`灵感源头生成 -> 场景拆解校验 -> 特征迁移重构 -> 专利合规预警 -> 中枢终审`

这套顺序的核心是：不要让无效灵感继续向下游流动。

## 工作流 1：存量爆款微创新

适用：

- 需要短期出结果
- 希望从成熟爆款中做低风险微创新
- 目标是 1 到 3 天内拿到可试产方向

执行顺序：

1. 爆款溯源 Agent 找高增长款、差评和结构缺陷
2. 特征迁移 Agent 提出 1 到 2 个低成本改造点
3. 场景拆解 Agent 判断真实使用是否成立
4. 专利预警 Agent 提前筛侵权和平台风险
5. 主 Agent 做成本、物流和差异化终审

典型输出：

- 现有品类的微创新版本
- 主体产品加可拆卸配件版本
- 面向车载、收纳、旅行等细分场景的变体

## 工作流 2：新领域原生创新

适用：

- 需要找蓝海机会
- 希望做高利润低竞争新品
- 目标是更偏中期的原生产品方向

执行顺序：

1. 新领域探测 Agent 找到正在升温但商品化不足的圈层
2. 场景拆解 Agent 还原用户完整动作链路和隐性痛点
3. 爆款溯源 Agent 查找其他赛道中解决同类痛点的成熟方案
4. 特征迁移 Agent 把成熟结构迁移过来
5. 专利预警 Agent 排查高风险形态并给重构建议
6. 主 Agent 做终审和优先级排序

典型输出：

- 小众兴趣圈层工具化产品
- 原本只有内容和讨论、尚未出现标准配套商品的新品
- 带配件矩阵可能性的新品母体

## 工作流 3：跨赛道颠覆性迁移

适用：

- 需要做高差异化方案
- 已有一批成熟特征库可复用
- 希望探索低竞争的新组合

执行顺序：

1. 特征迁移 Agent 从成熟特征库中抽取高复用特征
2. 主 Agent 找到低关联但痛点兼容的目标品类
3. 场景拆解 Agent 过滤不成立的组合
4. 专利预警 Agent 判断是否存在高近似结构风险
5. 主 Agent 输出最值得继续验证的方案

典型输出：

- 把收纳逻辑迁移到 DIY 工具
- 把连接结构迁移到居家组织用品
- 把冷感、磁吸、折叠、模块化等能力迁移到新赛道

## 并行与串行策略

### 并行模式

适合：

- 一次性产出多个方向
- 先广撒网再收敛

建议：

- 新领域探测 Agent 与爆款溯源 Agent 可先并行
- 特征迁移、场景拆解、专利预警建议半串行，避免重复浪费

### 串行模式

适合：

- 做高质量、低风险的精品方案
- 需要可直接试产的结论

建议：

- 优先场景校验，再做特征重构
- 最后才给出正式产品定义

## 失败回退机制

- 场景失败：回退到特征迁移 Agent 重新选特征
- 专利失败：回退到特征迁移 Agent 规避结构近似
- 成本失败：回退到爆款 Agent 寻找更低复杂度母体
- 物流失败：回退到主 Agent 约束产品尺寸和包装方式

## 主 Agent 终审清单

- 用户为什么会买
- 与现有商品相比差异化在哪里
- 是否满足轻小件和物流要求
- 是否可解释成本和毛利
- 是否具备可规避侵权的路径
- 是否存在可扩展的配件矩阵
